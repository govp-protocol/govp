# Support

Use GitHub Discussions or issues for public implementation questions,
interoperability reports and documentation improvements once those facilities
are enabled. Include the GOVP version, operating system, Python version,
command, expected result and a minimal synthetic record.

Do not post private records, customer information, credentials or exploitable
vulnerability details publicly. Security reports go to
`research@gemacode.org` under [`SECURITY.md`](SECURITY.md).

Community support is provided on a best-effort basis. The open protocol and
reference verifier do not include service-level commitments, hosted operation,
issuer key custody, certification or integration support.
