# Public protocol scope

This repository contains only the material required to implement and verify
the open GOVP-1 protocol:

- the normative record specification;
- machine-readable schemas and conformance vectors;
- a minimal reference verifier and command-line interface;
- synthetic examples, tests and release tooling.

It intentionally excludes issuing products, user and tenant management,
control panels, hosted services, orchestration, observers, operational data,
customer integrations, private keys and commercial extensions. Those systems
are neither disclosed nor required to claim GOVP-1 conformance.

Compatibility claims are technical claims. They do not imply certification,
endorsement or permission to use project trademarks beyond accurate
descriptive reference.
