# Published review evidence

This directory preserves external review artifacts for reproducibility and
transparency. A report applies only to the exact target hash it names.

These artifacts are machine-assisted technical reviews, not certifications,
legal opinions or substitutes for a commissioned professional security audit.
Later releases must not inherit an earlier verdict merely because findings
were addressed.

Historical reviews of private publication candidates are deliberately not
republished: their prose names systems outside the public protocol scope even
when confirming that no source from those systems was present. Removing those
references is part of the public-data boundary, not an attempt to transfer an
old verdict to a new release.

The public audit trail starts with the reproducible GOVP 0.1.10 release
evidence. Its package includes exact source and distribution hashes, provenance,
test commands and a reviewer prompt. A reviewer-produced report will be added
only if it names the exact 0.1.10 artifact hash and contains no non-public
product, customer, personal or operational information.
